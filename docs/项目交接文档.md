# TOLS 项目交接文档

> 本文档面向新接手人员，包含从环境安装到本地运行、服务器部署运维的完整指南。
> 更新日期：2026-05-12（新增 Docker 一键部署方案）

---

## 一、项目概述

本项目是一个游戏平台系统，分为四个主要模块：

| 模块 | 目录 | 技术栈 | 端口 | 说明 |
|------|------|--------|------|------|
| **fe** | `fe/` | Next.js 16 + React 19 + TypeScript | 3000 | 用户前端（游戏大厅、钱包、个人中心） |
| **be** | `be/` | Go + Fiber + GORM + MySQL | 3555 | 主业务后端（用户、支付、游戏API） |
| **behddfw** | `behddfw/` | Go + Fiber + GORM + MySQL | 3557 | 游戏大厅独立后端 |
| **bg** | `bg/` | Gin-Vue-Admin 框架 | 8888/8080 | 管理后台（服务端+前端） |

**依赖服务：**
- MySQL 8.0+（主数据库）
- Redis 6.0+（缓存、Session）

## 二、环境准备

### 2.1 安装 Node.js（前端需要）

**Windows：**
1. 访问 https://nodejs.org/ ，下载 LTS 版本（建议 v20+）
2. 运行安装包，一路下一步
3. 打开 CMD/PowerShell 验证：
   ```bash
   node -v   # 应显示 v20.x.x 或更高
   npm -v    # 应显示 10.x.x 或更高
   ```

**macOS：**
```bash
brew install node
```

**Linux：**
```bash
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt-get install -y nodejs
```

### 2.2 安装 Go（后端需要）

**所有平台：**
1. 访问 https://go.dev/dl/ ，下载 Go 1.24+（项目要求）
2. 安装并配置环境变量
3. 验证：
   ```bash
   go version   # 应显示 go1.24.x
   ```

**配置国内代理（加速依赖下载）：**
```bash
go env -w GO111MODULE=on
go env -w GOPROXY=https://goproxy.cn,direct
```

### 2.3 安装 MySQL

**Windows：**
1. 下载 MySQL Installer：https://dev.mysql.com/downloads/installer/
2. 选择 "Server only" 安装
3. 记住 root 密码，启用端口 3306

**Docker（推荐用于本地开发）：**
```bash
docker run -d \
  --name mysql8 \
  -p 3306:3306 \
  -e MYSQL_ROOT_PASSWORD=your_password \
  -e MYSQL_DATABASE=star \
  -e MYSQL_DATABASE=tols \
  mysql:8.0 \
  --character-set-server=utf8mb4 \
  --collation-server=utf8mb4_unicode_ci
```

### 2.4 安装 Redis

**Windows：**
下载：https://github.com/microsoftarchive/redis/releases
或安装 Memurai（Redis Windows 替代品）

**macOS：**
```bash
brew install redis
brew services start redis
```

**Linux：**
```bash
sudo apt-get install redis-server
sudo systemctl start redis
```

**Docker：**
```bash
docker run -d --name redis6 -p 6379:6379 redis:6.0
```

### 2.5 安装 Git

下载 https://git-scm.com/downloads 安装即可。

## 七、Docker 一键部署（推荐新手使用）

> 如果你不想逐个安装 Node.js、Go，也不想手动编译后端，推荐使用 Docker 一键部署。
> MySQL 和 Redis 使用宝塔面板已有的（或外部已有的），Docker 只跑 **be 后端** 和 **fe 前端**。

### 7.1 前提条件

1. **已安装 Docker**（见下方安装步骤）
2. **MySQL 已运行**（宝塔面板已安装，或已有外部 MySQL）
3. **Redis 已运行**（宝塔面板已安装，或已有外部 Redis）
4. **数据库 `star` 已创建**，并导入了 `be/tols.sql`

### 7.2 安装 Docker

**Windows：**
1. 访问 https://www.docker.com/products/docker-desktop
2. 下载 Docker Desktop 安装包，双击安装，按提示重启
3. 启动 Docker Desktop，等待左下角显示绿色

**macOS：**
```bash
brew install --cask docker
```

**Linux：**
```bash
curl -fsSL https://get.docker.com | sh
sudo usermod -aG docker $USER
# 退出重新登录
```

### 7.3 项目已准备的 Docker 文件

项目根目录已包含以下 Docker 相关文件：

```
tols/
├── docker-compose.yml       # 编排 be + fe

├── start-docker.bat         # Windows 一键启动脚本

├── fe/
```

### 7.4 配置说明

`.env` 文件是核心配置，需要填写：

```env
# ============================================
# 数据库连接（连接宝塔面板或外部的 MySQL / Redis）
# ============================================

# MySQL 地址
# 本地测试: host.docker.internal（容器访问宿主机）
# 服务器部署: 填宝塔服务器的实际 IP，如 192.168.1.100
DB_HOST=host.docker.internal
DB_PORT=3306
DB_PASSWORD=你的MySQL密码
DB_NAME=star

# Redis 地址
REDIS_HOST=host.docker.internal
REDIS_PORT=6379

# ============================================
# 前端配置
# ============================================

# 后端 API 地址（浏览器可访问）
NEXT_PUBLIC_API_BASE_URL=http://localhost:3555

# Clerk 认证 Key（从 https://dashboard.clerk.com/ 获取）
NEXT_PUBLIC_CLERK_PUBLISHABLE_KEY=pk_test_你的公钥
CLERK_SECRET_KEY=sk_test_你的私钥
```

**关于 DB_HOST 的说明：**
- Docker 容器内的 `127.0.0.1` 是它自己，**不是宿主机**
- 要访问宿主机的 MySQL，用 `host.docker.internal`（Win/Mac 直接可用，Linux 需 Docker 20.10+）
- 服务器部署时，直接填宝塔服务器的**实际内网 IP** 最稳

## 八、服务器部署运维（非 Docker 方式）

### 8.1 生产环境架构

```
用户 -> Nginx (443) -> 前端/后端服务

Nginx 反向代理配置示例：
- /          -> fe (Next.js, 端口 3000)
- /api       -> be (Fiber, 端口 3555)
- /bgapi     -> bg/server (Gin, 端口 8888)
- /admin     -> bg/web (dist 静态文件)

> behddfw（端口 3557）是另外的游戏项目，不在此维护范围。
```

### 8.2 Nginx 配置示例

```nginx
server {
    listen 80;
    server_name gg.vazhenina.com;
    return 301 https://$server_name$request_uri;
}

server {
    listen 443 ssl;
    server_name gg.vazhenina.com;

    ssl_certificate /path/to/cert.pem;
    ssl_certificate_key /path/to/key.pem;

    # 用户前端
    location / {
        proxy_pass http://127.0.0.1:3000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }

    # 主后端 API
    location /api/ {
        proxy_pass http://127.0.0.1:3555/;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }

    # 管理后台 API
    location /bgapi/ {
        proxy_pass http://127.0.0.1:8888/;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }

    # 管理后台前端（静态文件）
    location /admin/ {
        alias /path/to/bg/web/dist/;
        try_files $uri $uri/ /admin/index.html;
    }
}
```

### 8.4 Linux 服务化部署（systemd）

为 Go 后端创建 systemd 服务：

```bash
# 创建服务文件
sudo tee /etc/systemd/system/be.service << 'EOF'
[Unit]
Description=TOLS Main Backend
After=network.target mysql.service redis.service

[Service]
Type=simple
User=www
WorkingDirectory=/path/to/tols/be
ExecStart=/path/to/tols/be/be-server
Restart=on-failure
RestartSec=5

[Install]
WantedBy=multi-user.target
EOF

# 重载配置
sudo systemctl daemon-reload

# 启动服务
sudo systemctl enable be
sudo systemctl start be

# 查看状态
sudo systemctl status be
sudo journalctl -u be -f
```

## 十一、常见问题

### Q1: `go mod tidy` 下载依赖很慢？
```bash
go env -w GOPROXY=https://goproxy.cn,direct
```

### Q2: 前端 `npm install` 报错？
```bash
# 清除缓存重试
npm cache clean --force
rm -rf node_modules package-lock.json
npm install
```

### Q3: MySQL 连接失败？
- 检查 MySQL 是否运行：`mysql -u root -p`
- 检查 config.json 中的 dbDsn 密码是否正确
- 检查数据库 `star` 是否已创建

### Q4: Redis 连接失败？
- 检查 Redis 是否运行：`redis-cli ping`（应返回 PONG）
- 检查 config.json 中的 redisNode 地址

### Q5: be 和 behddfw 有什么区别？
- `be`（端口 3555）是主业务后端，处理用户、支付、活动等
- `behddfw`（端口 3557）是游戏大厅后端，处理游戏列表、启动游戏等
- 两者结构相似但服务不同业务，部署时需要同时启动

### Q6: bg 管理后台如何初始化？
- 首次启动 bg/server 会自动创建表
- 访问前端页面进行初始化设置管理员账号
- 或参考 gin-vue-admin 官方文档：https://gin-vue-admin.com/
