# 游戏平台活动功能设计文档

## 项目概述

本文档描述游戏平台新增活动功能的详细设计方案，包括：
1. 储值返利活动 - 每日充值返利（4天递增奖励）
2. 轮盘抽奖活动 - 每日抽coupon，充值达标后返利
3. 输返活动 - 活动期间净亏损按6%返还

## 活动功能简介

### 1. 储值返利活动 (Recharge Rebate)

**活动规则：**
- 活动期间内，用户每日充值 ≥ $3，按阶段获得返利：
  - 第1日充值：额外赠送充值金额的 50%
  - 第2日充值：额外赠送充值金额的 75%
  - 第3日充值：额外赠送充值金额的 100%
  - 第4日充值：额外赠送充值金额的 150%

**关键特性：**
- 活动有明确的开始时间和结束时间，可重复开启
- 每个活动周期内，用户独立计算4天进度
- 每日独立计算，需在当日完成充值
- 奖励自动发放到用户余额
- 活动可配置为周期性活动（如每月自动开启一次）

### 2. 轮盘抽奖活动 (Daily Coupon Wheel)

**活动规则：**
- 用户每日可抽奖获得随机coupon
- coupon有不同面值（如 $1, $2, $5, $10, $50, $100）
- 用户充值 ≥ 配置金额（默认$3）后可激活coupon
- 激活后奖励自动发放到用户余额

**关键特性：**
- 每日限抽1次
- coupon有效期24小时
- 充值门槛可配置

### 3. 输返活动 (Loss Rebate)

**活动规则：**
- 活动期间内，用户净亏损（下注总额 - 派彩总额）按 **6%** 比例返还
- 活动有明确的开始时间和持续时间（如7天、14天）
- 返还计算方式：
  - 净亏损 = MAX(0, 下注总额 - 派彩总额)
  - 返还金额 = 净亏损 × 6%
- 返还发放：活动结束后统一发放或达到门槛后实时发放

**关键特性：**
- 活动周期可配置（开始时间 + 持续时间）
- 支持按日累计或按活动周期累计
- 实时展示当前亏损/返还金额
- 可设置最低返还门槛（如亏损≥$10才返还）

## 技术栈

- **后端 (be/)**: Go + Fiber + GORM + MySQL
- **前端 (fe/)**: Next.js + React + TypeScript + Tailwind CSS
- **管理后台 (bg/)**: Gin-Vue-Admin
